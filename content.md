To cause a keyboard key like `Enter`{.kbd} to render in the Atomic Learning Platform, surrounding the name of a key with backticks and add `{.kbd}` after the closing backtick. For example the phrase "`Ctrl`{.kbd} + `C`{.kbd} copies text to the clipboard" was created with the following text in the Markdown file:

```markdown
`Ctrl`{.kbd} + `C`{.kbd} copies text to the clipboard
```
